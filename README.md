**Multitool** — это модульное Android-приложение, объединяющее базовые инструменты повседневного использования с системой расширяемых плагинов. Проект разрабатывается в рамках учебной программы командой студентов.

---

## 🚀 Основные возможности

Приложение предоставляет инфраструктуру сторонним разработчикам для быстрой разработки удобных расширений (плагинов), ускоряющих повседневные рутинные задачи. 

### 1. Базовый функционал — предустановленные расширения

* **Будильник:** Надежный старт твоего дня.
* **Заметки:** Быстрая фиксация идей и важных списков дел.

### 2. Магазин расширений

Главная фишка проекта — отдельная вкладка с плагинами, которые можно установить по желанию:

> Это может быть всё что угодно! Благодаря удобному API и документации, Вы можете разработать своё расширение, например:
> * **Погода:** Актуальный прогноз в один клик.
> * **Full-screen Clock:** Стильные часы на весь экран (режим док-станции).
> * **Birthday Reminder:** Удобные уведомления, чтобы не забыть поздравить близких.

## 📥 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone https://github.com/StepanDevOps/multitool.git

```


2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации **Gradle**.
4. Запустите проект на эмуляторе или реальном устройстве.
